# CB011911-TinyML-IDS
Explainable TinyML IDS for Smart Home Edge Devices — FYP CB011911

## Data
Raw dataset files and processed splits are not included in this repository 
due to file size constraints. Download CICIoT2023 from:
https://www.unb.ca/cic/datasets/iotdataset-2023.html
Then run data-pipeline/01_load_data.ipynb followed by 
data-pipeline/02_preprocessing.ipynb to regenerate all splits.
